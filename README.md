## 🌌 Overview

This repository contains the source code for my personal developer portfolio. Engineered with a dark, cyberpunk-inspired aesthetic, the site utilizes WebGL and advanced animation libraries to create an immersive user experience that reflects my focus on cutting-edge technology and scalable AI systems.

## ✨ Key Features

* **3D Particle Engine:** A custom-built WebGL background using Three.js, featuring depth fog, linear interpolation (LERP) for buttery-smooth mouse tracking, and organic sine-wave breathing effects.
* **Camera Parallax:** The entire 3D scene reacts dynamically to cursor movement, shifting the camera perspective to create a deep sense of scale.
* **Advanced Animations:** Scroll-triggered element reveals, text-scramble initialization sequences, and hover-triggered CSS glitch effects powered by GSAP.
* **Smooth Scrolling:** Integrated Lenis for hardware-accelerated, fluid vertical scrolling.
* **Magnetic UI:** Custom cursor logic with magnetic buttons and text links that physically pull toward the user's mouse.
* **Glassmorphism Design:** Modern, frosted-glass UI components heavily customized with Tailwind CSS utility classes.

## 🛠️ Tech Stack

**Core**
* HTML5 / Vanilla JavaScript
* [Tailwind CSS](https://tailwindcss.com/) (Styling & Utility Classes)

**Graphics & Animation**
* [Three.js](https://threejs.org/) (WebGL 3D Rendering)
* [GSAP](https://greensock.com/gsap/) (Complex timeline animations)
* [ScrollTrigger](https://greensock.com/scrolltrigger/) (Scroll-linked animations)
* [Lenis](https://lenis.studiofreight.com/) (Smooth scroll mathematics)
